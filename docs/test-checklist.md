# Чек-лист ручной проверки «Ноготочки. Онлайн-запись»

Список проверок для ручного прохода по сервису. Собран из трех источников:

* сценарии использования из паспорта продукта — [`docs/pasport-produkta.md`](pasport-produkta.md);
* раздел «Ограничения и риски» того же паспорта;
* журнал разработки [`docs/development-log.md`](development-log.md) и журнал верстки [`docs/frontend-log.md`](frontend-log.md) — все, что уже чинили, проверяется повторно;

плюс проверки, которые подсказал код: обработка ошибок API на экранах, доступ к разделам сотрудников, пути к файлам, ограничения частоты запросов.

Чек-лист разбит на четыре части: **Гость**, **Клиент**, **Администратор** (вместе с разделом мастера) и **Безопасность**. Примерно половина проверок — это ошибочные действия: пустые формы, неверные данные, чужой номер записи в адресе, отмена посреди оформления.

У каждой проверки есть строка **Результат**.

## Подготовка

1. База с тестовыми данными: остановите сервер и выполните из папки `server/` команду `npm run db:reset`. Без тестовых данных не будет ни мастеров с графиком, ни блокировок, ни готовых записей, и половина проверок окажется бессмысленной.
2. Запустите сервер и интерфейс: из папки проекта `node tools/dev.mjs`. Интерфейс — **http://127.0.0.1:8090**, API — порт 3000.
3. Письма. Если почта в `server/.env` не настроена, коды и ссылки сервер печатает в свой журнал — смотрите окно, в котором он запущен.
4. Учетные записи из тестовых данных (пароли — из `server/.env`, переменные `SEED_*`):

| Роль | Логин |
|---|---|
| Клиентка Мария Кузнецова | `maria@example.com` |
| Администратор | `admin@example.com` |
| Мастер Анна Ковалева | `anna@example.com` |
| Клиентка Ольга Белова без пароля (записана по телефону) | телефон `+79035556677` |

5. Что лежит в тестовых данных и на что опираются проверки:

| Что | Значение |
|---|---|
| Режим студии | вторник — суббота, 10:00–20:00; воскресенье и понедельник закрыты |
| Анна Ковалева, «Мастер» | ср — сб, 10:00–18:00; ногти и дизайн; по четвергам обед 13:00–14:00 |
| Марина Орлова, «Мастер» | ср — сб, 11:00–20:00; только брови; по пятницам личное время 15:00–17:00 |
| Елена Смирнова, «Мастер» | вт, чт, сб, 10:00–19:00; ногти и брови, дизайн не делает; ближайшая суббота — выходной, через 10 дней — отпуск на неделю |
| Правила записи | шаг слотов 30 минут, горизонт 90 дней, не раньше чем за 2 часа, бронь 10 минут, отмена и перенос за 24 часа |

6. Часовой пояс студии — `Europe/Moscow`. Если ваш компьютер в другом поясе, время на экранах все равно должно быть московским.
7. После проверок безопасности (подбор пароля, блокировки доступа, удаление аккаунта) верните базу: остановите сервер и снова выполните `npm run db:reset`.
