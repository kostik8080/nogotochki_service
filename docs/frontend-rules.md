# Правила верстки

Правила для всех, кто верстает клиентскую часть «Ноготочки. Онлайн-запись», — для людей и ИИ-ассистентов.

1. **Верстаем обычными HTML, CSS и JS, без сборщиков и фреймворков.** Черновой фронт для проверки API (`web-draft/`, на React + Vite + TypeScript) образцом не служит: его код в страницы не переносим.
2. **Один экран прототипа — одна страница в папке `web`.** Черновой фронт в `web/` не кладем: он живет в `web-draft/`.
3. **Все обращения к серверу идут через `web/js/api.js`.** Внутри страниц запросов быть не должно. Файл создается вместе с первой страницей; в черновом фронте ту же роль играет `web-draft/src/api.ts`.
4. **Цвета, шрифты и размеры берем только из `web/tokens.css`.** Новых значений не добавляем.
5. **Папку `server` не трогаем.** Если для экрана не хватает данных, сначала говорим об этом владельцу проекта.
6. **Папку `Prototype` («Прототип») не меняем и не переименовываем** — она только образец.
7. **Ошибку от API показываем клиенту текстом на экране**, а не только в консоли.
8. **Экраны мастера и администратора пока не верстаем.**

## Перед версткой нового экрана

Посмотрите его строку в карте клиентских экранов [`docs/ui-map.md`](ui-map.md): что экран показывает, из каких эндпоинтов берет данные, какие вызывает кнопками, куда ведут переходы и какие решения по расхождениям с API для него уже приняты.
