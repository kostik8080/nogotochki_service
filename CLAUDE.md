# Ноготочки. Онлайн-запись

Паспорт продукта хранится в `docs/pasport-produkta.md` и подключается сюда целиком. Правьте паспорт там, а не в этом файле.

@docs/pasport-produkta.md

Другие документы проекта:

* `docs/karta-svyazey-prototipa.xlsx` — карта связей прототипа: экраны, переходы, сценарии;
* `docs/db-schema.md` — схема базы данных SQLite;
* `docs/api.md` — REST API сервера: эндпоинты, коды ответа, формат времени (UTC) и денег (копейки);
* `docs/frontend-rules.md` — правила верстки клиентской части. Прочитайте перед любой версткой;
* `docs/ui-map.md` — карта клиентских экранов: данные, кнопки и переходы каждого экрана, решения по расхождениям с API;
* `docs/frontend-log.md` — журнал подключения сверстанных клиентских экранов: файл, эндпоинты и поля ответа каждого экрана, что чинили по ходу верстки. Дополняйте, когда верстаете новый экран;
* `docs/database.md` — как устроена база в коде, почему выбраны такие решения, драйвер `node:sqlite`, требование Node.js 24.7+ и правила изменения базы. Прочитайте перед любой работой с базой, миграциями, тестовыми данными или деплоем и дополняйте по мере развития проекта;
* `docs/development-log.md` — журнал разработки: что и когда менялось в проекте, и настройки, которые задаются на сервере. Дополняйте строкой в конец таблицы при каждом заметном изменении.
